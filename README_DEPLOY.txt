PANKHURI & SHUBHAM — GITHUB PAGES FILES

Folder contents:
- index.html: main website file
- images/: the three replacement festivities images
- assets/: other media extracted from the HTML (intro background, story/venue images, video, audio, etc.)

IMPORTANT: Keep index.html, images/, and assets/ together at the same level in the repository. Do not upload only index.html.

GitHub Pages update steps:
1. Open your GitHub repository in a browser.
2. Open the branch/folder currently used by GitHub Pages (usually the main branch and repository root).
3. Upload the CONTENTS of this package: index.html, the images folder, and the assets folder. Do not upload the ZIP itself.
4. If GitHub asks whether to replace index.html, choose to replace/overwrite it. Upload both folders as folders, preserving their names and contents.
5. Commit the changes to the same branch that Pages publishes from.
6. Wait for the Pages deployment to finish, then refresh the website. On desktop, hard refresh with Ctrl+Shift+R (Windows) or Cmd+Shift+R (Mac). On mobile, reopen the site or clear its cached page if old content persists.

If the repository's browser editor will not accept a large upload, use GitHub Desktop or git to copy these files into the local repository, then commit and push.
